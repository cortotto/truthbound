Welcome to Truthbound; a website designed to unify truth by letting you post what you believe to be true and work towards ratifying it as well as the truths of others.

HOW IT WORKS

1. Enter a statement into the Chamber and select the type of truth it represents to you: Objective, Intersubjective, or Subjective.
2. The statement appears in the chamber with one vote (the vote you just made). Others can now ratify it by voting on what truth they identify that statement with.
3. Once a statement has reached 100 votes it becomes ratified and is then sent to the archives or "leaderboards" where people can then like and comment on the truths they've ratified.
4. If a statement has no clear majority or in the event of a tie, the statement is moved to a fourth category in the leaderboards; Contested.

Work towards this project started when I was in college, learning about websites and truth tables. AI wasn't as big a deal back then, but now that it is... voila!

I hope this site helps you find contentment in what you truly believe in.
